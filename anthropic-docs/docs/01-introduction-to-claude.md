## Visão Geral

Claude é uma plataforma de IA de alto desempenho construída pela Anthropic, que se destaca em tarefas de linguagem, raciocínio, análise e trabalho de codificação.

## Modelos Claude Mais Recentes

**Claude Sonnet 4.5** - Modelo mais avançado para agentes complexos, codificação e tarefas sofisticadas

**Claude Haiku 4.5** - Modelo mais rápido com capacidades quase de fronteira

**Claude Opus 4.1** - Modelo especializado para tarefas avançadas de raciocínio

*Para interação conversacional, visite [claude.ai](http://www.claude.ai)*

## Capacidades Principais

**Geração de Texto e Código**
- Resumo de texto
- Perguntas e respostas
- Extração de dados
- Tradução
- Explicação de código
- Geração de código

**Visão**
- Processamento de entrada visual
- Análise
- Geração de texto/código a partir de imagens
